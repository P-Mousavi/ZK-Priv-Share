New coverage: one fresh canonical deployment per size/repetition, N identities and funded stakes, precommitted N pending CTI state leaves, sequential same-index state updates, access/delivery/acknowledgement, ratings, report/two votes/real slash; separate reward batch append/claim with capacity boundary. Individual successful receipts, full public proof inputs, standalone verifier transaction gas, proof time, deployment and configuration receipts, state assertions, failures and preserved-source/artifact hashes accompany each workload. Registration and existing state proving are integrated, not replaced.

Tree limits: identity/stake/state circuits depth 7 (128 slots). State contract stores a root, not an incremental insertion tree: pending leaves must be committed at initialization; no implemented post-deployment empty-slot allocation. Reward depth 5 (32 append-only slots); claiming does not reclaim a slot or change the root. Rating is mapping counters, not a tree. CTI/access/dispute maps grow; only malicious threshold outcomes are supported by the canonical resolver. Separate stakes are required for N independent slashes because a slash consumes the deposit. No ETH transfer/burn is performed by canonical slashing. No reward eligibility link to a particular CTI is implemented.

The proof dimensions are fixed at depth 7 or 5; changing populated leaf count does not enlarge the circuit. Any population-related timing differences are measurements, not an asymptotic growth claim. Identity root equality remains disabled in identity.circom; production verification is real but does not establish complete identity membership. Baseline costs remain separate because semantics and economics differ.

Regression execution confirmed 77 passing and 3 pre-existing failures in the broad legacy benchmark glob, using an untouched copy created before additions. The three failures above are excluded from current canonical coverage. The canonical four-file command passed 4/4. Full contract/E2E/circuit regression passed 126 + 1 + 29.
